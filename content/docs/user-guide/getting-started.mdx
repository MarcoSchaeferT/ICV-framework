Follow these initial steps to get oriented in ICV:

<Steps>

### Open ICV

Open the URL supplied by your organization. During local use, the default address is `http://localhost:3000`.

### Choose a view

- Use a Vis. Interface for a prepared, topic-specific overview.
- Use a world or regional view to investigate spatial patterns.
- Use the raw-data view to inspect records and attributes.
- Use Upload when you need to add an authorized CSV dataset.

### Understand the interface

ICV uses three recurring navigation areas:

1. **Top navigation**: Opens primary Vis. Interfaces, data tools, publications, and documentation.
2. **Left sidebar**: Contains disease-specific filters and specialist views when enabled.
3. **Vis. Interface cards**: Present charts, tables, maps, legends, and interactive filters.

### Change language

Use the application's language selector in the top bar to switch interface controls between English and German. Labels and metadata follow the selected language when translations are available. This documentation portal remains in English.

</Steps>
