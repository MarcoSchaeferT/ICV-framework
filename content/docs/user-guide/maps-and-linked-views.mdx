## Navigate a map

- Drag to pan and use the configured zoom controls to change scale.
- Use the coordinate and zoom display, when present, to retain spatial context.
- Read the legend before comparing colors or presence markers.
- Hover or select a supported feature to open its tooltip.

## Understand linked selections

Some Vis. Interfaces connect a map, table, and chart through shared selection state. Selecting a region, grid cell, or table row can highlight the corresponding item in another view. Clear the selection before starting an unrelated comparison.

<ShowCovGuard>

In the world COVID Vis. Interface, click an ocean area in either map to clear the selected country and show all countries again.

</ShowCovGuard>

## Compare responsibly

Check the aggregation level, observation date, unit, color scale, and missing-data behavior. Similar colors do not imply equal values when legends or scales differ.

<Callout type="info">
  Available interactions depend on the Vis. Interface configuration.
