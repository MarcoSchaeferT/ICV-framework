This guide explains how to use ICV without requiring knowledge of its source code.

For descriptions of the available datasets and individual interface controls, see [Help & dataset details](/en/docs).

## Choose a workflow

- [Getting started](./getting-started): understand the interface and choose a view.
- [Upload data](./uploading-data): prepare a CSV file and follow its processing status.
- [Explore data](./exploring-data): work with tables, charts, filters, and metadata.
- [Use maps and linked views](./maps-and-linked-views): navigate spatial data and coordinated selections.
- [Troubleshoot](./troubleshooting): resolve common usage problems.

<Callout type="info">
  The available datasets and controls depend on the active deployment and selected Vis. Interface.
</Callout>
