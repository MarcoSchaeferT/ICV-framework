## Select a dataset

Choose a dataset before configuring a generic chart. Only datasets available in the current deployment are listed.

## Configure a chart

1. Select a chart type or open a prepared chart card.
2. Choose an X-axis or category field.
3. Choose a numeric Y-axis or value field.
4. Apply an available row limit, date range, or category filter.
5. Read the unit and description from the metadata before interpreting the result.

## Inspect a table

Use tables to verify individual records behind an aggregate or visual pattern. Sorting and selection affect only the controls exposed by the current table.

## Interpret missing or partial results

An empty chart can mean that no dataset is selected, a filter has no matching rows, metadata marks a field as unavailable, or the backend request failed. Clear filters one at a time before changing the dataset.
