[**ICV TypeScript API**](..)

***

> **CardPropsClass**(`id`, `headline`, `description`, `footer`, `bgColor?`): [`CardPropsClass`](../interfaces/CardPropsClass)

Creates a Vis. Interface card configuration without optional information panels.

## Parameters

### id

`string`

Stable DOM and Swapy slot identifier.

### headline

`string`

Visible card title.

### description

`string`

Supporting description below the title.

### footer

`string`

Attribution or footer text.

### bgColor?

`string` = `"bg-surface-light"`

Tailwind background utility.

## Returns

[`CardPropsClass`](../interfaces/CardPropsClass)

A card configuration accepted by [CardWrapper](CardWrapper) and `SGridPlotCard`.
