[**ICV TypeScript API**](..)

***

> **getActiveStringFilters**(`filter?`): `string`[]

Normalizes an optional string or string array into non-empty filters.

## Parameters

### filter?

[`MapStringFilter`](../type-aliases/MapStringFilter)

One substring, alternatives, or no filter.

## Returns

`string`[]

Truthy string values in their original order; an empty array if disabled.
