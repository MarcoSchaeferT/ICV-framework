[**ICV TypeScript API**](..)

***

> **getGoodReadableRange**(`dataMin`, `dataMax`): \[`number`, `number`\]

Calculates human-readable axis range bounds `[min, max]` by rounding to powers of 10.

## Parameters

### dataMin

`number`

Raw dataset minimum value.

### dataMax

`number`

Raw dataset maximum value.

## Returns

\[`number`, `number`\]

Human-friendly axis scale range tuple `[adjustedMin, adjustedMax]`.
