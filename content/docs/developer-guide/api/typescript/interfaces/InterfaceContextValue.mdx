[**ICV TypeScript API**](..)

***

Global reactive state interface for the ICV (Interactive Context-rich Views) framework.

Serves as the central event bus and synchronized state contract across multi-view Vis. Interface elements,
coordinating state parameters between spatial maps, time-series line charts, data tables, and donut overlays.

## Remarks

To prevent infinite render loops when multiple visual widgets receive state updates, components accept
boolean flags like `isApplyContextData` and `isSetIntialContextDataFromComponent`. High-frequency mouse events
are routed through `mouseEvent` (a React `MutableRefObject`) to bypass React re-render cycles during rapid cursor movements.

## See

 - [InterfaceContextProvider](../functions/InterfaceContextProvider) for the React context provider implementation.
 - [useInterfaceContext](../functions/useInterfaceContext) for consuming this context within React Vis. Interface widgets.
 - [LeafD3MapLayerProps](../functions/LeafD3MapLayerProps) for the Leaflet spatial-layer contract.
 - [useGetJSONData](../functions/useGetJSONData) for the shared data-fetching hook.

## Example

```tsx
import { useInterfaceContext } from "@/framework";

function SelectionControls() {
const {
  curFeature,
  setCurFeature,
  mapCoords,
  setMapCoords,
  isPresenceData,
  setIsPresenceData,
} = useInterfaceContext();

  return <button onClick={() => setCurFeature("mosquito_density_albopictus")}>
    Select mosquito density at zoom {mapCoords.zoom}
  </button>;
}
```
