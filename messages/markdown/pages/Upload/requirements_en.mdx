# Upload: File Requirements

## CSV format

- Save the file as a UTF-8 encoded `.csv` with a header row and comma-separated fields.
- Use unique column names without spaces around the comma separators.
- Write decimal values with a period, for example `12.34`.
- Keep the filename shorter than 70 characters. The upload form rejects files larger than 2,500 MB.
- Do not include an `id` column: ICV creates a record ID for each imported row.

The filename, without `.csv`, determines the dataset name. Uploading another file with the same resulting name replaces the existing dataset and its rows. Check the filename before uploading a new snapshot.

## Geometry for grid-based maps

Grid datasets need a column named `geometry`. Write each grid cell as a rectangular WKT `POLYGON`, with longitude before latitude. List the four corners and repeat the first corner as the fifth point to close the polygon. Enclose the whole value in double quotes so its internal commas stay in one CSV field.

Other tabular datasets may omit `geometry`; the upload then skips country assignment and the dataset cannot provide grid cells to a map.

For example, this CSV defines one rectangular grid cell and a numeric feature:

```csv
geometry,precipitation
"POLYGON ((10 50, 11 50, 11 51, 10 51, 10 50))",22.5
```

## Filenames used by map filters

- For probability datasets, include `probability` in the filename, for example `mosquito_habitat_probability_2020.csv`.
- For training datasets, include `named` and omit `probability`, for example `mosquito_training_data_named_2020.csv`.

These words help the corresponding dataset filters find uploaded files. The dataset must also have the columns expected by the chosen view.
