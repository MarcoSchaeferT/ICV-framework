This ENSO (El Niño–Southern Oscillation) showcase compares seasonal forecasts of habitat suitability for *Aedes aegypti* and *Aedes albopictus* with the corresponding climatological reference values. The dataset is updated monthly and contains predictions for the following six months. Use the controls above the visualizations to select a mosquito species and forecast month. The **Forecast Map** displays the habitat suitability derived from the SVM prediction model, which uses SEAS5 seasonal climate forecasts as input, while the **Reference Map** shows the 2000–2025 reference mean for the same calendar month. The maps are synchronized for direct comparison.

Select a grid cell in the Forecast Map to update the chart above the maps. It compares the ERA5-based annual reference cycle (mean ±1 standard deviation) with the available SEAS5 forecasts for **temperature in 2 m height**, **dewpoint temperature**, **wind speed**, and **total precipitation**, as well as the **habitat suitability** computed by the SVM model from these climate variables. The selected forecast month is highlighted in red.
