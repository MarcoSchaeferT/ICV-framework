| Action | How to use it |
| --- | --- |
| **Pan** | Drag the map to move the view. |
| **Zoom** | Use the mouse wheel or map controls to zoom in or out. |
| **Hover** | Point to a colored cell to read its value. |
| **Click** | Click a selectable country or cell to focus it. |
| **Controls** | Change the dataset, feature, color scale, or optional layers above the map, where available. |
