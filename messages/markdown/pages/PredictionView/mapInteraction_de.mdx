| Aktion | Verwendung |
| --- | --- |
| **Verschieben** | Ziehen Sie die Karte, um die Ansicht zu verschieben. |
| **Zoomen** | Zoomen Sie mit dem Mausrad oder den Kartensteuerelementen hinein oder heraus. |
| **Hover** | Zeigen Sie auf eine eingefärbte Zelle, um ihren Wert zu sehen. |
| **Klicken** | Klicken Sie auf ein auswählbares Land oder eine Zelle, um es beziehungsweise sie zu fokussieren. |
| **Steuerelemente** | Ändern Sie oberhalb der Karte Datensatz, Merkmal, Farbskala oder optionale Ebenen, sofern verfügbar. |
