| Aktion | Verwendung |
| --- | --- |
| **Verschieben und zoomen** | Ziehen Sie die Karte oder verwenden Sie das Mausrad und die Kartensteuerelemente. |
| **Wert ablesen** | Zeigen Sie auf eine eingefärbte Rasterzelle. |
| **Bereich auswählen** | Klicken Sie auf ein Land, um die verknüpften Diagramme zu aktualisieren. |
| **Darstellung ändern** | Wählen Sie in den Kartensteuerelementen Datensatz, Merkmal, Farbskala oder optionale Ebene. |
| **Ansichten vergleichen** | Wechseln Sie rechts zwischen Liniendiagrammen und der verknüpften Detailkarte. |
