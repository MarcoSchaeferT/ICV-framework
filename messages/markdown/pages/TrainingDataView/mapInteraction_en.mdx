| Action | How to use it |
| --- | --- |
| **Pan and zoom** | Drag the map or use the mouse wheel and map controls. |
| **Read a value** | Hover over a colored grid cell. |
| **Select an area** | Click a country to update the linked charts. |
| **Change the display** | Choose a dataset, feature, color scale, or optional layer in the map controls. |
| **Compare views** | Switch the panel on the right between line charts and the linked detail map. |
